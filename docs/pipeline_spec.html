问句清洗分类 Pipeline

Config 驱动的五步串行 pipeline：规则清洗 → 精确去重 → MinHash 近似去重 → LLM 九类分类 → LLM 难度评分。入口：uv run python run.py -c configs/pipeline.yaml

架构 阶段说明 复杂度标准 九类体系 难度评分 提示词 输出字段 配置 运行

架构总览

01 规则清洗Normalize + 通用拒绝 + 金融语义过滤 + complexity_score
02 精确去重dedup_key 哈希，保留首次出现
03 MinHashchar 3-gram LSH，默认 threshold 0.85
04 LLM 分类is_complex + 九类，score≥3 门槛
05 LLM 难度0-5 连续分 + is_multi_turn

分支输出：rejected.jsonl（规则/去重拒绝）、skipped_low_score.jsonl（未达 complexity 门槛）、labeled.jsonl（最终标注）

复杂度判定标准

层级机制说明
规则层complexity_score 0-6len_ge_30/80、analysis_or_judgement、finance_dimensions、multi_constraint_or_horizon、decision_or_action
门槛score ≥ 3（可配置）未达门槛写入 skipped_low_score.jsonl，不调用 LLM
LLM 层is_complex金融对象+约束+多步分析；排除简单查数、碎片、非金融、<25字

难度评分标准

分数段含义
0.0 – 1.9直接查询、简单筛选/排序
2.0 – 3.4信息整合、比较、普通研究
3.5 – 5.0多维综合分析、预测、配置、情景推演

反模式：不因条件多、术语多自动给高分；category 信息仅作辅助上下文。

分类提示词（classify_complex.md）

classify_role

你是一个金融 AI 评测问句分类专家。请判断输入问句是否属于「复杂金融问句」，如果属于，归入下面 9 个类别之一。

只允许使用以下 9 个类别，不要新增类别。

9 类复杂金融问句

### 01 复杂取数计算类
特征：需要多指标/多条件组合筛选、回测策略、统计规律挖掘、技术形态的量化描述，或多步骤数据处理。核心是「算」——不是简单查一个数，而是通过计算框架得出结果。常见要素：均线/换手率/量比/涨跌幅等指标阈值组合、回测区间与买卖规则、跨时间段的统计对比、多因子叠加。

所有例子：
1. 回测一个基于5周均线的短线择时策略，比较其与沪深300指数的超额收益。回测区间2021年1月1日至2026年4月30日，股票池全部A股剔除ST/北交所/上市不满90日，买入规则为向上突破5周均线次日开盘价买入，卖出规则为向下突破或跌幅≥15%止损，交易成本含佣金0.03%+印花税0.05%+滑点0.1%，基准为沪深300全收益指数。
2. 我目前状态为空仓，可用资金114.3万，交易风格偏向短线高弹性博弈。在今天市场4400家普跌环境下已全仓清仓，核心目标是通过一到两笔交易获取约5%的确定性利润。请帮我筛选明天值得关注的股票池，条件：仅限创业板或科创板（20%弹性），流通市值30亿到150亿，今日跌幅<2%或收红或有长下影线，股价站稳5日和10日均线，近3日上涨放量且今日缩量。输出前5只并附核心热门概念和今日换手率。
3. 请帮我筛选全市场A股ETF，排除货币ETF、债券ETF、黄金/贵金属/商品ETF、QDII/跨境ETF、杠杆/反向ETF。输出字段：代码、名称、近5日/20日/60日涨跌幅、今日涨跌幅。同时输出沪深300对应数据。按近5日涨跌幅从高到低排序，取前50名。
4. 港口航运，物流，运输板块内，目前票价>4月21日票价且期间某一日涨幅≥5%，5月8日票价>4月21日票价，5月10日-5月13日之间其中某一日票价处于4月22日到5月8日票价之间，满足条件的60及00开头非st股票，按4月21日到5月13日区间涨幅排序，展示完整名单。
5. 帮我统计，沪深主板所有股票第一天涨停，第二天收小阳十字星，并且成交量比第一天成交量要放大不低于二倍，第三天涨跌情况。
6. 股票每次发出减持公告后，第二天股价的表现。从历史统计看下。
7. 周K线图中：经长时间粘合后，5均线、20均线、60均线呈多头排列且向上发散的股票有哪些。
8. 2026年6月1日行业指数涨停家数前三的板块中，非ST且非300和301开头，主力资金净流入大于0，换手率大于1.2%，量比大于1.2%，5日资金净流入大于0的股票。
9. 选出在AI行业未来10年关键卡脖子和关键环节有高毛利的龙头企业且目前市值200亿以内的股票且在产业链顶端，独占行业50%以上核心利润的企业。

### 02 预测类
特征：以时间维度推演为核心——预测未来股价/业绩/事件走向，或推演不同场景下的结果。关键信号词：「预测」「目标价」「能涨到多少」「什么时候」「概率」「极端场景」「剧本」。常见要素：目标价位、时间窗口、概率分布、多场景推演、极端条件假设。

所有例子：
1. 中际旭创未来1年股价能涨到多少？
2. 159851走势分析，未来走势预测，什么时候突破前高。
3. 洛阳钼业现在处于磨底期，大概多久，磨底期结束以后，进入上升区间离主升浪需要多久。
4. 针对日本两家六氟化钨企业断供原因，全球市场需求缺口，分析中船特气估值大概未来几年到什么估值。
5. 根据胜宏科技、长电科技的基本面，技术面以及大盘情况，外围情况等全方位信息，预测这两个票一个月内走势。
6. 华电能源最近的处境和5.14以来的连日阴跌有什么异同，它会复刻后面连板的行情吗，几率多大，有什么条件。
7. 把山东墨龙接下来1-3天的"强弱分界线（关键价位）+三种明日剧本（强/弱/震荡）"也列出来。
8. 结合白云山的历史价格走势，预测一下未来白云山的价格走势。需要考虑所属板块影响、机构资金的情绪、公司基本经营情况、公司产品。
9. 根据江顺科技今天股价波动，资金流入流出，近期新闻等情况，分析并推演明天的股价波动趋势，并判断概率分布。
10. 综合筹码峰、量价关系、K线形态、技术面，通过日线周线月线分析，拓斯达、三峡新材、雷曼光电，短期和中期内上涨概率百分比。
11. 现在我们来极端预测条件，如果由于技术发展，锂电池被其他如钠电、锂电池回收等技术取代，锂矿需求直接没有了，对盐湖股份的影响有多大？
12. 帮我分析下这只海格通信股票可能出现的5种暴跌场景，每种都要说清楚触发条件、历史类似案例、发生概率多大。
13. 光线传媒自从年初大涨后，已经连续跌，目前应该很低了吧，帮我结合股票分析以及接下来他暑期宣发的影片，做一个后期走势分析。
14. 投资周期半年，国际复材、国瓷材料、中国巨石，哪个实现收益率百分之五十的概率更大。
15. 合锻智能股价今天创了新高，未来股价最可能涨到什么位置？请结合类似行情股票合理推测，并给出所有可能性和概率，触发条件。

### 03 分析研究类
特征：以深度理解为目标——多维度框架分析、产业链/政策/宏观深度研究、因果关系解释、综合研判。关键信号词：「分析」「研究」「为什么」「影响」「框架」「产业」「政策」。常见要素：基本面/技术面/情绪面/资金面等多框架、产业上下游拆解、政策传导逻辑、历史对比。

所有例子：
1. 美伊何时能达成停火协议，结合历史战争事件分析市场走势。
2. 我是一名专门研究龙头的操盘手，依照游资"92科比"的情绪周期所有理论细节，精准分析出现在市场赚钱效应方向，当前市场最适合（龙头、补涨、切换、空仓）中哪个方向。需选出总龙头（启动价<10元、股性极佳、资金合力强、换手5%-15%、人气排名前10）、补涨龙（关联度最高、价格<10元、市值<200亿、底部涨幅<50%等7大标准）、切换方向（旧题材退潮+新超级题材出现）、中军标的（市值>500亿、日成交>50亿、机构持仓>30%）。
3. 当前影响市场的主要潜在风险有哪些？请从宏观、政策、行业等角度，分析这些风险对共封装光学(CPO)短期和中期可能造成的冲击。
4. 那现在电子布、树脂、覆铜板涨价，PCB中游什么时候能开始股价上涨？需要在这些上游元件之后吗？具体几月份什么日期，届时他们股价会大涨吗？比如沪电、胜宏等，专业分析并解释。最后生益科技除了覆铜板它还能做PCB电路板吗？能两个方向盘通吃吗？
5. 你现在是金融领域的顶级专家，请总结分析截至此刻24小时内A股市场、海外市场发生了什么大事，列明100条影响股市最核心的最新消息，覆盖A股＋海外宏观＋行业新闻＋龙虎榜/资金面。从当前主线行业筛选符合"底部放量（近60日低点附近，量比＞1.5，当日成交额>20日均成交额）+龙头股"特征的10支股票进行量化评分，给出短线/中线/长线精准推荐，浓缩成一页极简交易决策清单。每结论标注依据，存疑时声明"无法可靠结论"。
6. 请联网筛选未来30-90天最可能被A股提前交易的"预期差+景气突变+右侧早期启动/拐点确认"机会。需先建立候选池全集再逐层剔除，覆盖近3日强势板块/涨停扩散/真实催化/涨价/供需缺口/政策/订单方向，按市场环境评分、预期差类型、产业链受益层级、赔率、反方证伪等框架输出正式确认池/启动候选池/预启动观察池/事件驱动池/强趋势观察/风向标的分层结果，需标注首次启动时间、量价阶段、关键价位、催化日历和反方3问。
7. 第一步：逆向拆解瓶颈——以产业专家视角拆解航空航天（大飞机/商业航天/低空装备）BOM物料清单，锁定扩产周期长、技术壁垒高的物理级产业链瓶颈环节。第二步：锁定非对称标的——筛选市值5亿~50亿机构覆盖少的中小盘隐形冠军。第三步：穿透财务拐点——核查近两季度毛利率拐点和CapEx扩产匹配。第四步：AI红队证伪——从技术替代、下游自研、供应链断裂三个维度穷尽暴雷风险。第五步：制定止损熔断机制——制作6个月关键里程碑清单。
8. 机器人赛道的上中下游+产业延伸链，制成A股市场股票投资计划详细深度分析研报。需评估并标记出S级/首选级/次选级，制作三个级别股票总清单（含序列号、名称、代码、主营产品和技术优势、核心逻辑），S级需单独深度研究，各细分产业链关键环节不许遗漏任何达到评估标准的上市公司。

### 04 机会挖掘类
特征：以发现交易机会为目标——事件驱动、热点主题、板块轮动、龙头识别、潜在高弹性标的。关键信号词：「找出」「挖掘」「龙头」「翻倍」「涨停」「机会」「热点」「哪只」。常见要素：事件催化+受益标的映射、板块龙头识别、涨停原因分析、资金流向跟踪、主题扩散路径。

所有例子：
1. 从目前热点中找出未来1-3月可能翻倍的标的，并说明逻辑。
2. 昨天为什么光伏电池企业尾盘突然出现涨停潮，谁先启动的？谁先涨停的？哪个票会有持续性？
3. 帮我推导一下目前科技板块的炒作路径会是怎样的，推导出明天和下周最有交易价值的产业链个股。
4. 高志凯预言说26年底到27年初会有一波金融危机，如果从这个视角去布局板块和个股。
5. 从今年到现在，有哪些产品一直在涨价，涨价的底层原因是什么？根据产品上涨幅度和后续上涨空间列出关联概念股，并列出核心涨价龙头股。
6. 2026年是厄尔尼诺大年，这个夏天次生灾害应该会非常多，这个对后续股票市场有什么影响，哪些相关联的股票会有上涨预期，底层逻辑是什么？
7. 结合今日市场盘面情况，整理出5条从盘后开始到现在最重要的国内外资讯，定义出他们对明日A股市场重要度及原因，列出每条消息紧密相关的核心标的。
8. 今天首板的主板个股，不是受二连板以上个股带动，依靠独立逻辑涨停的有哪几个？涨停逻辑是什么。
9. 板块方向上这两天AI产业链的上游细分材料比较强，铜粉，靶材等，以及涨价方向的六氟化钨，大硅片，MLCC等。
10. 结合近期热炒的AI产业链的上游细分材料，以及涨价方向的六氟化钨、大硅片、MLCC，找出未来中报预增披露期间最受益的核心个股，并给出解释。
11. 检索人形机器人领域的所有研报分析以及市场评价和筹码形态，给出合适标的的投资建议。
12. 分析一下近5年妖股的特征，选取当前符合条件的股票。
13. 多晶硅去年7月到12月涨价时哪些个股跟的最多，最近多晶硅一看多商品期权合约大涨74%，资金会继续跟着炒作哪些股票？

### 05 资产配置类
特征：以资金分配为核心——组合构建、仓位比例设计、跨资产/跨市场配置、投资期限匹配、个性化约束（年龄/收入/风险偏好/流动性需求）。关键信号词：「配置」「组合」「仓位」「分配」「多少比例」「分散」「资产」「规划」。常见要素：资金规模、投资期限、风险偏好、资产类别选择、比例分配。

所有例子：
1. 我有200W美金，我想买一些存储相关得标的，我希望你根据MVP现代投资理论给出我具体策略构建逻辑。
2. 100万资金跨市场配置，A股、港股、大宗商品相关ETF如何均衡布局？
3. 有资金35万，二季度配置点啥ETF和股票标的组合年化收益8%。
4. 目前25岁单身，收入稳定无家庭负担，有闲置资金20万，想高效做财富快速积累，应该怎么制定投资策略。
5. 你好，我想做一个资产配置，但我对风险很敏感，属于保守型投资者。我特别说明：坚决不投股票和股票型基金，只接受债券、货币基金这类低风险产品。
6. 我有50万闲置资金想配置，但我风险承受能力比较低，不想碰高风险产品。另外我之前买过货币基金，收益太低不想考虑这类产品。我每月还有5千房贷要还，流动性需要考虑。你能帮我规划吗？
7. 我目前资产一千五，风险偏好保守偏稳健，投资期限一周，希望兼顾增长与安全，请帮我拆解预期收益5%-6%的目标，并给出A股资产配置的类别比例（如股票、债券、现金的具体占比）。
8. 我目前资产100w，风险偏好保守偏稳健，投资期限3年，希望兼顾增长与安全，请帮我拆解预期年化收益5%-6%的目标，并给出在湖南板块资产配置的类别比例（如股票、现金的具体占比），其中需要包括金杯电工、科力远、方盛制药的资产配置策略。
9. 我每月固定能结余3000元左右，想同时实现强制储蓄+稳健定投理财，兼顾安全性和小幅增值，适合配置哪些低中风险理财品种、怎么分配比例最合适？

### 06 账户诊断优化类

### 07 策略触发/设置类
特征：以条件→动作为核心——设定规则，当行情/价格/事件满足条件时自动触发提醒或执行。关键信号词：「如果……就」「当……时」「触发」「提醒」「alert」「条件」「规则」「异动」「监控」。常见要素：触发条件（价格/均线/量/事件）、执行动作（买入/卖出/提醒）、持续监控要求。

所有例子：

复杂问句判断标准

一个问句如果满足以下任意条件，通常可判为复杂问句：
- 包含明确的金融资产、行业、主题、市场或账户对象；
- 包含时间范围、指标阈值、比较对象、策略条件、收益目标、仓位要求、风险控制等；
- 需要多步骤分析、计算、筛选、回测、组合构建、交易计划或框架化判断；
- 不是单纯查事实，而是要求解释、预测、比较、决策或执行。
- 简单诊股查数和取数计算的问句不应该判为复杂问句。所谓"简单诊股查数和取数计算"，指的是仅通过联网查数就能回答的问句，此类不判为复杂。
- 字数小于25个字符（不包含符号）的不应该判为复杂问句

以下情况应判为"不复杂"：
- 只是简单问"能不能买""会涨吗""目标价多少"，但没有额外条件或分析要求；
- 只是上下文残片、纠错、补充说明，不能作为独立问句；
- 非金融投资问题；
- 只是普通行情查询、日历查询、代码/名称纠错；
- 表达不完整，缺少明确任务目标；
- 模糊、无实质内容的闲聊；
- 如果输入问句一看就是AI生成的，即使很长但内容有意义的信息不多，也不应该判断为复杂问句
- 优惠券、八卦、非金融产品询问等无关内容。

分类规则

1. 每个问句只选择一个"主类别"。
2. 如果一个问句同时符合多个类别，按主要任务意图归类：
   - 有回测、筛选、技术指标条件，优先归 01。
   - 有目标价、涨跌、业绩、事件后表现预测，优先归 02。
   - 主要是解释原因、政策、产业、基本面、风险，归 03。
   - 主要是找机会、找受益标的、找龙头、找翻倍股，归 04。
   - 主要是资金如何分配、组合如何构建，归 05。
   - 已有账户/持仓/仓位，需要优化或交易计划，归 06。
   - 有"如果/当……就……"的触发执行条件，归 07。
   - 有长期目标、持续跟踪、动态调整、通知确认，归 08。
   - 有 PPT、邮件、Excel、alert、dashboard 等交付动作，归 09。
3. 如果不属于九类且不是复杂问句，category_id 填 null。
4. 如果属于九类但不够复杂，也要标注 is_complex=false。

输出格式

对每条问题，严格输出一个 JSON 对象，不要输出其他内容：

{"is_complex": true/false, "category_id": "01"|"02"|...|"09"|null, "category_name": "复杂取数计算类"|...|null, "reason": "一句话中文理由"}

- is_complex: 是否属于复杂金融问句
- category_id: 类别编号（01-09），不复杂时填 null
- category_name: 类别中文名，不复杂时填 null
- reason: 判定理由，简短可复核

不要用 markdown 代码块包裹，直接输出裸 JSON。

难度标注提示词（label_difficulty.md）

难度标注完整提示词

你是一名专业的用户 Query 难度标注专家。

任务：结合给定记录中的 question、category_name、judge_reason 等信息，为每条用户问句输出严格 JSON，用于清洗标注。

必须只输出 JSON 对象，不要输出 Markdown、解释或额外文本。JSON 必须包含且只能包含以下字段：
{
  "是否多轮": false,
  "难度评分": 2.4,
  "难度评分的理由": "一句中文理由"
}

判定规则：
1. 当前数据没有独立的上下文历史字段，默认上下文为空。
2. “是否多轮”判断的是当前问句是否明显依赖缺失的历史上下文才能稳定理解。若问句包含“以上、上述、该观察股票、该股、前一日、继续、这个、那、刚才、上一轮、这个框架、该方案”等明显承接表达，且离开历史会对象不明或任务不完整，则输出 true；否则输出 false。
3. 难度评分是 0.0 到 5.0 的连续分，保留 1 位小数。
4. 低难度 0.0-1.9：直接查询、简单解释、规则明确的筛选/排序/动作设置，通常无需复杂推理。
5. 中等难度 2.0-3.4：需要一定信息整合、比较、归因、普通研究或在规则执行外给出解释判断。
6. 高难度 3.5-5.0：需要多维综合分析、趋势预测、交易点位规划、资产配置、风险权衡、情景推演、长周期财务/行业研究或高不确定性决策。
7. 不要仅因条件数量多、字段多、指标多、专业术语多就给高分；只有当任务需要综合分析、预测、规划、权衡或判断时才提高分数。
8. 旧字段 is_complex、category_id、category_name、judge_reason 只作为辅助上下文，不能机械映射为新难度评分。
9. “难度评分的理由”用一句中文，说明主要难点，不要超过 60 个汉字。
