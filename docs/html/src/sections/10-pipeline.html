步骤 方式 做什么
precheck 数据预检
规则
在创建 LLM 客户端前检查坏行比例、合格 turn 和 chain 覆盖率；严重结构问题立即中止。
preclean 输入清洗
规则
统一不同来源的对话格式；过滤坏行、空会话；按 trace 去重。
segment 会话分段
LLM
让 LLM 按主题把长会话切成几个独立片段，单句会话保持整段。
rule_gate 候选筛选
规则
扔掉模板残留、超长等明显噪声；要求片段必须真正动用了工具链。
judge 语义判定
LLM
三步漏斗：先看值不值得、再看够不够复杂、最后归到对应类别；任一步骤不通过即丢弃。
verify 独立复判
LLM
换一个独立视角再判一次；带前文指代复核；任何一轮与首次判定相悖即丢弃。
answer_gate 质量门
规则
剔除未跑完的轮次（last_event_type ≠ runFinished）、空回答、拒绝话术、长度不足 50 字、以逗号冒号破折号结尾的截断回答。
post 去重与翻译
规则LLM
合并同一模板下的近似样本；非中文回答翻译为简体中文，原文保留。
