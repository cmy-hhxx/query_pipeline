清洗与标注流程

输入aime/input.jsonl · iwencai/chat.jsonl 最终产物cleaned_queries.jsonl（hard + normal）
  1. preclean 输入清洗 格式嗅探 · 坏行 · 去重
  2. segment 会话分段 LLM · 主题切 2–4 段
  3. rule_gate 候选筛选 规则 · 噪声拒绝 + 工具门槛
  4. judge 语义判定 LLM · value→complexity→classify
  5. verify 独立复判 LLM · hard 5 轮 / normal 2 轮
  6. answer_gate 回答质量门 规则 · 完成态 / 非拒绝 / ≥50 字
  7. post 去重与翻译 规则 + LLM · 模板合并 + 译简中
  8. ✓ 进入样本 accepted
value_rejected 无保留价值
failed LLM 失败丢弃 rejected 复判与难度相悖 rejected 回答不完整 / 拒绝话术 rejected 重复样本合并

一次真实运行的数据漏斗（aime/0806，500 会话）

  1. 500输入会话
  2. 674分段
  3. 568候选
  4. 457有价值
  5. 274复判通过
  6. 260质量门通过
  7. 239去重后输出

其中 complex 257 行（hard）+ normal 200 行（judge 产出）→ verify 通过 274 → answer_gate 拒绝 14 → dedup 合并 21 → 最终 239 行；翻译 195 条（中文占比 < 30% 才译）。

步骤 方式 判定 / 动作
preclean 输入清洗
规则 · code
格式自动嗅探（session / chat）；坏行落盘；trace 去重；空会话过滤；适配统一 Session
segment 会话分段
语义 · LLM
按主题切 2–4 段；chat / 单句会话回退整段 whole_session
rule_gate 候选筛选
规则 · code
噪声拒绝（模板残留 / 低价值 / 超长）+ 三信号 AND：工具调用 ≥7、步骤 ≥1、工具种 ≥2
judge 语义判定
语义 · LLM
漏斗三步：value_gate 有无价值 → complexity_gate 是否复杂 → classify 归 9 类复杂 / 16 类普通；任一失败丢弃（fail-closed）
verify 独立复判
语义 · LLM
带前文指代复核；hard 5 轮 / normal 2 轮 级联从严，任一轮与难度相悖即弃；LLM 失败丢弃（fail-closed）
answer_gate 回答质量门
规则 · code
结构信号 last_event_type=runFinished + 内容信号：拒绝话术 / 截断标点 / 回答过短 <50 字
post 去重与翻译
规则 · code语义 · LLM
同模板合并（非槽骨架一致）+ token-Jaccard ≥ 0.80 去重；中文占比 <30% 才 LLM 译简中，原文保留
